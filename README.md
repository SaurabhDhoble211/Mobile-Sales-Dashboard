# 📊 Mobile Sales Dashboard – Power BI Project

## 🚀 Project Overview

This project is an interactive **Mobile Sales Dashboard** created using **Microsoft Power BI** to analyze mobile sales performance, customer behavior, and business trends.

The dashboard helps businesses track:

* Total sales performance
* Quantity sold
* Customer ratings
* Transaction trends
* Brand-wise analysis
* City-wise sales distribution
* Payment method insights
* Time intelligence metrics (MTD, QTD, YTD)

---

# 🛠️ Tools & Technologies Used

* **Power BI Desktop**
* **DAX (Data Analysis Expressions)**
* **Power Query**
* **Data Modeling**
* **Interactive Visualizations**

# 📑 Dataset Information

The dataset contains the following key fields:

| Column Name      | Description                          |
| ---------------- | ------------------------------------ |
| Transaction ID   | Unique transaction identifier        |
| Date             | Sales transaction date               |
| Brand            | Mobile brand name                    |
| Mobile Model     | Model of the mobile device           |
| Units Sold       | Number of units sold                 |
| Price Per Unit   | Selling price per unit               |
| Customer Name    | Customer details                     |
| Customer Age     | Age of customer                      |
| City             | Sales location                       |
| Payment Method   | Mode of payment                      |
| Customer Ratings | Product/customer satisfaction rating |
| Rating Status    | Rating category/status               |

---

# 📈 Key KPIs Implemented

The dashboard includes the following DAX measures:

| KPI                   | Purpose                        |
| --------------------- | ------------------------------ |
| Total Sales           | Overall revenue generated      |
| Total Quantity        | Total units sold               |
| Transactions          | Total number of transactions   |
| Average Price         | Average selling price          |
| MTD                   | Month-To-Date sales            |
| QTD                   | Quarter-To-Date sales          |
| YTD                   | Year-To-Date sales             |
| Same Period Last Year | Historical comparison analysis |
